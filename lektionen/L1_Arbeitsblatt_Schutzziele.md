# Die vier Schutzziele

**Lektion 1 – Partnerarbeit | ca. 10 Min.**

## Ziel

Sie können die vier Schutzziele der Informationssicherheit unterscheiden und an Beispielen
erklären. Sie wissen, welches davon Verschlüsselung allein sicherstellt.

## Die vier Schutzziele

| Schutzziel | Leitfrage | Beispiel |
|---|---|---|
| **Vertraulichkeit** | Können nur Berechtigte die Information lesen? | Niemand ausser Ihnen und Ihrer Ärztin kennt den Befund. |
| **Integrität** | Ist die Information unverändert? | Die Kontonummer in der Überweisung ist noch dieselbe. |
| **Authentizität** | Stammt die Information wirklich von dem, der sie zu senden vorgibt? | Die Mail stammt wirklich von Ihrer Bank. |
| **Verbindlichkeit** | Kann der Absender später nicht abstreiten, sie gesendet zu haben? | Wer einen Vertrag digital unterschreibt, kann es nicht leugnen. |

In der Fachsprache will meist *Alice* ihrem Kollegen *Bob* eine Nachricht schicken, und
*Eve* (von englisch *eavesdropper*, Lauscherin) hört mit oder versucht, die Nachricht zu
manipulieren.

### Aufgabe 1 – Szenarien zuordnen

Ordnen Sie jedem Szenario das Schutzziel zu, das **verletzt** wird oder **geschützt**
werden soll. Manchmal passen zwei.

| Nr. | Szenario | Schutzziel(e) |
|---|---|---|
| 1 | Ihre Krankenakte soll nur Ihre Ärztin lesen können. | |
| 2 | Jemand ändert in einer Online-Überweisung unbemerkt die Kontonummer des Empfängers. | |
| 3 | Sie erhalten eine Mail «von Ihrer Bank» – in Wahrheit stammt sie von Betrügern. | |
| 4 | Eine Kundin bestellt online ein teures Velo und behauptet danach, sie habe nie bestellt. | |
| 5 | Im Gratis-WLAN am Bahnhof liest jemand Ihre Nachrichten mit. | |
| 6 | Ein Schüler fängt die Notenliste ab und ändert seine Note, bevor sie weitergeleitet wird. | |
| 7 | Ihr Laptop installiert ein Update, das angeblich von Microsoft stammt. | |
| 8 | Ein Mietvertrag wird digital unterschrieben. Später will der Mieter nichts davon wissen. | |

### Aufgabe 2 – Was leistet Verschlüsselung?

Verschlüsselung macht eine Nachricht für Unbefugte unlesbar. Welches der vier Schutzziele
kann sie damit **allein** sicherstellen? Begründen Sie an Szenario 3 oder 6, warum die
anderen Schutzziele nicht automatisch erfüllt sind.

**Gut zu wissen:** In der IT-Sicherheit wird oft noch ein fünftes Schutzziel genannt:
**Verfügbarkeit** – die Daten sollen da sein, wenn man sie braucht. Dagegen hilft
Kryptografie nicht, sondern zum Beispiel ein Backup (siehe Einheit Cybersicherheit).

**Vorschau:** In den Lektionen 1–4 geht es um die **Vertraulichkeit**. In Lektion 5 lernen
Sie die Werkzeuge für Integrität, Authentizität und Verbindlichkeit kennen: Hashfunktionen
und digitale Signaturen.
